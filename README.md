# 💼 Dream Job

Dream Job is a modern **frontend job portal web application** built to provide users with a simple and user-friendly platform for exploring job opportunities.

The project focuses on building a clean UI, responsive design, job searching, filtering, and an easy-to-use job browsing experience.

## ⚙️ Installation & Setup

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project folder

```bash
cd dream-job
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local development URL shown in your terminal.
